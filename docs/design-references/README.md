# Design References

These are the approved reference designs used to build
the app UI. If you need to redesign any section, use
these files as the visual baseline.

| File | What it covers |
|------|----------------|
| case_log_reference.html | Full case log app — CSS, layout, all form sections |
| popup_reference.html | Chrome extension popup — full interactive demo |
| edit_reference.html | Edit button design in saved cases panel |

Open any file directly in a browser to preview the design.
All CSS uses the same design tokens as the live app
(--accent, --surface, --green, etc).
